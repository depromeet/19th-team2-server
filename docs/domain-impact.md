# 도메인 영향 범위

> 자동 생성 문서입니다. 직접 고치지 말고 `docs/domains.yaml` · 코드를 바꾼 뒤 `./gradlew test` 로 다시 만듭니다.
>
> `global` 은 모든 도메인이 의존하므로 표 · 그래프에서 뺐습니다. `global` 을 바꾸면 전 도메인이 영향을 받습니다.

**기능 기획 시**: 바꿀 도메인의 "영향 범위" 칸에 있는 도메인도 함께 검토합니다.

| 도메인 | 설명 | 의존하는 도메인 | 나를 직접 의존 | 영향 범위 (바꾸면 영향받는 도메인) |
|---|---|---|---|---|
| - | 아직 도메인이 없습니다 | - | - | - |

## 의존 그래프

```mermaid
graph LR
```

점선(`-.->`)은 아직 코드가 없는 기획 중 도메인의 예정된 의존입니다.
